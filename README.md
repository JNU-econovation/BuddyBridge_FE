# Buddy Bridge

## Description

---

일상에서 도움이 필요한 장애인과 도움을 주고자 하는 지원자를 빠르고 간편하게 매칭시켜주는 웹플랫폼

## Requirements

- Next.js
- TypeScript
- Tanstack Query
- Zustand
